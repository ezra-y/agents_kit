# 弹窗 / Alert

可跑实例：通知横幅、自定义 Alert、弹窗替换、顶部通知、蜂群/毛玻璃弹窗 等提示形态。

- [NotificationBanner](https://github.com/Daltron/NotificationBanner) - 可定制的应用内通知横幅
- [SDCAlertView](https://github.com/sberrevoets/SDCAlertView) - 支持自定义内容的 Alert
- [PopupDialog](https://github.com/Orderella/PopupDialog) - 替代 UIAlertController 的弹窗
- [CDAlertView](https://github.com/candostdagdeviren/CDAlertView) - 高度可定制的 Swift 弹窗
- [CRToast](https://github.com/cruffenach/CRToast) - 状态栏/导航栏顶部通知
- [TKSwarmAlert](https://github.com/entotsu/TKSwarmAlert) - Swarm 风格蜂群动画弹窗
- [MIBlurPopup](https://github.com/MarioIannotta/MIBlurPopup) - 带毛玻璃背景的弹窗
- [SweetAlert-iOS](https://github.com/codestergit/SweetAlert-iOS) - JS SweetAlert 风格动画弹窗
- [GoogleWearAlert](https://github.com/AshRobinson/GoogleWearAlert) - Android Wear 风格确认视图
