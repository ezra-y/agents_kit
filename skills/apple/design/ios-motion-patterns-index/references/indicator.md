# 指示器 / Indicator

可跑实例：加载动画、分页指示、导航栏加载、HUD 弹出 等状态指示。

- [NVActivityIndicatorView](https://github.com/ninjaprox/NVActivityIndicatorView) - 海量加载动画合集
- [TKRubberIndicator](https://github.com/TBXark/TKRubberIndicator) - 橡胶弹性分页指示器
- [SpringIndicator](https://github.com/KyoheiG3/SpringIndicator) - Material 风格弹簧指示器+下拉刷新
- [BusyNavigationBar](https://github.com/gmertk/BusyNavigationBar) - 导航栏加载动画扩展
- [PKHUD](https://github.com/pkluz/PKHUD) - Apple HUD 风格弹出指示
