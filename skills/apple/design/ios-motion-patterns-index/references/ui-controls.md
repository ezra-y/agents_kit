# 界面控件 / UI

可跑实例：IB 设计动画、文字变形、分段控件、卡片、流体滑块、搜索、夜间模式、Markdown 视图 等通用控件。

- [IBAnimatable](https://github.com/IBAnimatable/IBAnimatable) - Interface Builder 内设计动画与转场
- [LTMorphingLabel](https://github.com/lexrus/LTMorphingLabel) - 文字变形演化 UILabel
- [Segmentio](https://github.com/Yalantis/Segmentio) - 带动画的顶/底分段控件
- [Cards](https://github.com/PaoloCuscela/Cards) - iOS 11 App Store 风格卡片
- [fluid-slider](https://github.com/Ramotion/fluid-slider) - 带气泡数值的流体滑块
- [StarWars.iOS](https://github.com/Yalantis/StarWars.iOS) - 视图碎裂成粉末的转场
- [YNSearch](https://github.com/younatics/YNSearch) - Pinterest 风格搜索视图
- [DKNightVersion](https://github.com/Draveness/DKNightVersion) - 多主题/夜间模式管理
- [Presentation](https://github.com/hyperoslo/Presentation) - 最简化的教程/发布说明动画页
- [AIFlatSwitch](https://github.com/cocoatoucher/AIFlatSwitch) - 扁平设计 IBDesignable 开关
- [MarkdownView](https://github.com/keitaoouchi/MarkdownView) - WKWebView 实现的 Markdown 视图
- [PARTagPicker](https://github.com/paulrolfe/PARTagPicker) - Tumblr/WordPress 风格标签选择器
- [MediaBrowser](https://github.com/younatics/MediaBrowser) - 图片/视频浏览缓存组件
