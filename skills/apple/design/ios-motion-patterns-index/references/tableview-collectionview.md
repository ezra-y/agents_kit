# 表格 / Tableview + 集合视图 / Collectionview

可跑实例：可展开单元格、下拉刷新、卡片滑动/层叠、视差 Sticky Header、弹性拉伸头、电子表格 等。表格与集合视图条目较少，合并存放。

## 表格 / Tableview

- [YNExpandableCell](https://github.com/younatics/YNExpandableCell) - 可展开折叠的 UITableViewCell
- [Pull-to-Refresh.Rentals-iOS](https://github.com/Yalantis/Pull-to-Refresh.Rentals-iOS) - Yalantis 自定义下拉刷新
- [SwipeCellKit](https://github.com/jerkoch/SwipeCellKit) - Mail.app 风格滑动操作单元格
- [folding-cell](https://github.com/Ramotion/folding-cell) - 折纸展开式单元格
- [elongation-preview](https://github.com/Ramotion/elongation-preview) - push-pop 伸缩预览

## 集合视图 / Collectionview

- [expanding-collection](https://github.com/Ramotion/expanding-collection) - 卡片展开成详情的集合视图
- [Koloda](https://github.com/Yalantis/Koloda) - Tinder 风格卡片滑动
- [MMCardView](https://github.com/MillmanY/MMCardView) - 钱包 App 风格层叠卡片
- [CSStickyHeaderFlowLayout](https://github.com/CSStickyHeaderFlowLayout/CSStickyHeaderFlowLayout) - 视差/Sticky Header 布局
- [GSKStretchyHeaderView](https://github.com/gskbyte/GSKStretchyHeaderView) - Twitter/Spotify 风格弹性拉伸头
- [SwiftSpreadsheet](https://github.com/stuffrabbit/SwiftSpreadsheet) - 可定制的电子表格布局
