# 菜单 / Menu

可跑实例：下拉、侧滑、圆形放射、断头台、动画 TabBar 等菜单形态与交互动画。

- [YNDropDownMenu](https://github.com/younatics/YNDropDownMenu) - 点击展开的自定义下拉菜单
- [Side-Menu.iOS](https://github.com/Yalantis/Side-Menu.iOS) - Yalantis 带动画侧边菜单
- [circle-menu](https://github.com/Ramotion/circle-menu) - 圆形按钮展开成放射状菜单
- [GuillotineMenu](https://github.com/Yalantis/GuillotineMenu) - 断头台式菜单转场动画
- [SideMenu](https://github.com/jonkykong/SideMenu) - Facebook 风格左右侧滑菜单
- [SlideMenuControllerSwift](https://github.com/dekatotoro/SlideMenuControllerSwift) - Google+/Feedly 风格滑动菜单
- [animated-tab-bar](https://github.com/Ramotion/animated-tab-bar) - TabBar 图标动画库
