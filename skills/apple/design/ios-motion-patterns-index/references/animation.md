# 动画 / Animation

可跑实例：通用动画库、骨架屏、矢量 SVG、启动屏、文字/GIF/天气特效等基础动画能力。

- [Spring](https://github.com/MengTo/Spring) - 简化 iOS 动画的通用库
- [SkeletonView](https://github.com/Juanpe/SkeletonView) - 骨架屏加载占位动画
- [Pastel](https://github.com/cruisediary/Pastel) - Instagram 风格渐变动画
- [Macaw](https://github.com/exyte/Macaw) - 支持 SVG 的矢量图形动画库
- [Stellar](https://github.com/AugustRush/Stellar) - 基于 UIDynamic 的物理动画
- [RevealingSplashView](https://github.com/PiXeL16/RevealingSplashView) - Twitter 风格启动屏揭示动画
- [Gecco](https://github.com/yukiasai/Gecco) - 新手引导高亮遮罩动画
- [ScrollableGraphView](https://github.com/philackm/ScrollableGraphView) - 自适应滚动折线图
- [GlitchLabel](https://github.com/kciter/GlitchLabel) - 故障艺术风格 UILabel
- [Highlighter](https://github.com/younatics/Highlighter) - 自动高亮 Cell 内 UILabel/UIButton 等元素
- [RQShineLabel](https://github.com/zipme/RQShineLabel) - Secret 风格闪光文字 UILabel
- [FLAnimatedImage](https://github.com/Flipboard/FLAnimatedImage) - 高性能 GIF 动图引擎
- [YLGIFImage](https://github.com/liyong03/YLGIFImage) - 低内存异步 GIF 解码
- [paper-switch](https://github.com/Ramotion/paper-switch) - 开关打开时涂色父视图
- [Windless](https://github.com/Interactive-Studio/Windless) - 隐形布局加载占位
- [Ease](https://github.com/roberthein/Ease) - 观察者模式+自定义弹簧动画
- [URWeatherView](https://github.com/jegumhon/URWeatherView) - 天气特效叠加视图
- [AnimatedMaskLabel](https://github.com/imjog/AnimatedMaskLabel) - 渐变微光闪烁 Label
