# 转场 / Transition

可跑实例：控制器转场、模态气泡、弹性拖拽、滚动转场、引导页 等过渡动画。

- [Hero](https://github.com/lkzhao/Hero) - 视图控制器转场框架
- [BubbleTransition](https://github.com/andreamazz/BubbleTransition) - 气泡展开式模态转场
- [ElasticTransition](https://github.com/lkzhao/ElasticTransition) - 弹性拖拽转场
- [Gemini](https://github.com/shoheiyokoyama/Gemini) - 基于滚动的丰富转场框架
- [AnimatedTransitionGallery](https://github.com/shu223/AnimatedTransitionGallery) - 自定义转场动画合集
- [JTMaterialTransition](https://github.com/jonathantribouharet/JTMaterialTransition) - Material Design 风格转场
- [preview-transition](https://github.com/Ramotion/preview-transition) - 预览画廊转场
- [AMWaveTransition](https://github.com/andreamazz/AMWaveTransition) - 列表波纹式转场
- [XLPagerTabStrip](https://github.com/xmartlabs/XLPagerTabStrip) - 可滑动切换的页面标签容器
- [PinterestSwift](https://github.com/demonnico/PinterestSwift) - Pinterest 风格转场 demo
- [TKSubmitTransition](https://github.com/entotsu/TKSubmitTransition) - 按钮加载+提交转场动画
- [AnimatedCollectionViewLayout](https://github.com/KelvinJin/AnimatedCollectionViewLayout) - 集合视图滚动转场布局
- [CKWaveCollectionViewTransition](https://github.com/CezaryKopacz/CKWaveCollectionViewTransition) - 集合视图波纹转场
- [BWWalkthrough](https://github.com/ariok/BWWalkthrough) - 自由设计的引导页 Walkthrough
