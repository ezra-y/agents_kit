# 主要公司设计系统

各大公司公开的完整设计系统（令牌 + 组件 + 规范 + 文档）。本文件承接 SKILL.md 精选之外的条目。来源：[awesome-design-systems](https://github.com/klaufel/awesome-design-systems)。

## 公司设计系统

- [Google Material Design](https://material.io/design) - Google's design system for intuitive, beautiful products.
- [Microsoft Fluent UI](https://fluentui.microsoft.com/) - Microsoft's open-source cross-platform design system (web/Apple/Android).
- [IBM Carbon](https://www.carbondesignsystem.com/) - IBM's open-source design system for products and experiences.
- [Shopify Polaris](https://polaris.shopify.com/) - Design system for great experiences for Shopify's merchants.
- [Atlassian Design Guidelines](https://atlassian.design/) - End-to-end design language for straightforward, beautiful experiences.
- [Salesforce Lightning Design System](https://www.lightningdesignsystem.com/) - Salesforce's design system for enterprise apps on the Lightning platform.
- [GitHub Primer](https://primer.style/) - Open-source design system powering GitHub's products.
- [GitLab Pajamas](https://design.gitlab.com/) - Resources, components, and design guidelines behind GitLab.
- [Firefox Photon Design System](https://design.firefox.com/photon) - Launch recognizable, enjoyable Firefox products and features faster.
- [Atlassian Atlaskit](https://atlaskit.atlassian.com/) - Atlassian's official UI library built to the Atlassian Design Guidelines.

> 更大全的公司 DS 列表见 https://github.com/alexpate/awesome-design-systems

## 通用设计系统资源

非特定公司的 DS 通用参考资料（规划、调研、社区）。

- [Design system checklist](https://designsystemchecklist.com/) - Open-source checklist to plan, build and grow a design system.
- [Design Systems Survey](https://designsystemssurvey.seesparkbox.com/) - Survey on design systems across 20+ industries.
- [Design.systems](https://design.systems/) - Resources for the design systems community.
- [Super friendly](https://superfriendlydesign.systems/) - Helping in-house teams make better digital products with design systems.
