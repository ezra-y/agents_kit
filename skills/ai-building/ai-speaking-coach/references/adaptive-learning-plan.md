# Adaptive Learning Plan

Read [curriculum-framework.md](curriculum-framework.md) before creating or materially revising the
learner's plan. The framework defines shared outcomes; this file defines how to choose the next
work for one learner.

## Gather Evidence

Learn these details naturally over several turns:

- The real situations in which the learner needs English, including people, medium, speed,
  formality, frequency, deadline, and consequence of a breakdown.
- Current listening and spontaneous speaking experience.
- Available study opportunities and realistic independent practice.
- Interests, language balance, correction tolerance, and available learner-owned material.

Collect short samples from at least two different tasks. Cover interpretive, interpersonal, and
presentational communication when feasible. Attach each observation to something the learner
actually did and label the initial profile `provisional`.

Do not claim an official CEFR or ACTFL rating. Do not turn onboarding into a long questionnaire.

## Generate The Plan

Create or update `runtime/learning-plan.md` from `assets/templates/learning-plan.md`.

### 1. Confirm One Primary Outcome

Phrase the goal as a real result, such as completing an initial job interview or handling a hotel
problem. When goals compete, compare importance, frequency, urgency, and current difficulty, then
let the learner confirm the current priority.

### 2. Define Active Target Tasks

Break the outcome into a small set of tasks the next teaching block can address. Two to four is the
`adaptive-plan-v1` default, not a research law. For each task record:

- Scenario, roles, and can-do target.
- Listening and interaction demands.
- Baseline evidence and observable success evidence.

Select expressions only after defining the task.

### 3. Identify The Current Bottleneck

Compare task demands with the capability evidence in
[curriculum-framework.md](curriculum-framework.md). Select one or two constraints most likely to
improve the target task:

- Input cannot be decoded.
- Meaning is known but retrieval is too slow.
- Necessary language or pragmatic control is missing.
- Wording is understandable but unnatural.
- Pronunciation or rhythm reduces intelligibility.
- Interaction cannot be maintained or repaired.

### 4. Create The Next Teaching Block

Use a rolling group of upcoming study opportunities, not a fixed calendar. Include:

- One active target task.
- Due retrieval and unresolved high-value errors.
- Comprehensible listening input.
- Meaningful interaction or output.
- Only the language, naturalness, or pronunciation work needed for the bottleneck.
- A fluency or transfer variation using familiar language.

Use Nation's
[Four Strands](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/2007-Four-strands.pdf)
as a rolling balance check, not a four-way timer for every lesson.

## Adapt From Class Evidence

Use this versioned decision policy:

| Evidence | Next move |
| --- | --- |
| Repeated breakdown despite support | Reduce linguistic load and teach the missing subskill |
| Success with substantial prompting | Keep the task and fade one support |
| Independent success in the familiar task | Add a meaningful variation |
| Independent transfer plus delayed retrieval | Advance the task or move the bottleneck |

After each class, update practiced items and errors, preserve one or two representative
task-level observations, and write the next teaching move. Replan when goals or availability
change, evidence contradicts the profile, active tasks transfer reliably, or repeated lessons show
no progress.

The progression threshold, number of active tasks, and review cadence are product policy. Spaced
practice supports distributed retrieval, but no fixed calendar is a universal Ebbinghaus schedule.

## Select Content

The current private corpus in `knowledge/items.jsonl` supplies expressions and patterns but does
not dictate their order. Add approved learner-owned material, generated supplements, and media
through the same item schema. Read [knowledge-schema.md](knowledge-schema.md) before changing the
corpus.

A future reusable distribution may split these sources into installable content packs. That
packaging plan is not part of the current private Skill.
