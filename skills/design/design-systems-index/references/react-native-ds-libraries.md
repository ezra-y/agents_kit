# React Native 设计系统库

React Native 跨平台开箱即用 UI 工具包。本文件承接 SKILL.md 精选之外的条目。来源：[awesome-react-design-systems](https://github.com/jbranchaud/awesome-react-design-systems)。

> React Native 组件与样式模式另见本地 `react-native-skills` skill；本文件只列成型 DS 组件库。

- [React Native Elements](https://reactnativeelements.com/) - Cross-platform React Native UI toolkit.
- [NativeBase](https://nativebase.io/) - GeekyAnts - essential cross-platform UI components for React Native & Vue Native.
- [Shoutem UI](https://github.com/shoutem/ui) - Shoutem - UI toolkit for professionally looking React Native apps.
- [Teaset](https://github.com/rilyu/teaset) - A UI library for React Native.
- [React Native Paper](https://reactnativepaper.com/) - Material Design-compliant React Native components.
