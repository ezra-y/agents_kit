# React 设计系统库

可直接采用的 React 组件库 / 企业级设计系统。本文件承接 SKILL.md 精选之外的条目。来源：[awesome-react-design-systems](https://github.com/jbranchaud/awesome-react-design-systems)。

- [Ant Design](https://ant.design/) - Ant Financial - design system for enterprise applications (Nature & Determinacy).
- [Material UI](https://mui.com/) - React components that implement Google's Material Design.
- [Blueprint](http://blueprintjs.com/) - Palantir - React-based UI toolkit for the web.
- [Grommet](http://grommet.io/) - Hewlett Packard - guidance and components from concept to real app.
- [Garden](https://garden.zendesk.com/react-components/) - Zendesk - curated collection of React UI components.
- [Backpack](https://backpack.github.io/) - Skyscanner - design resources and reusable components for Skyscanner products.
- [Ring UI](http://www.jetbrains.org/ring-ui/index.html) - JetBrains - UI building blocks for JetBrains web products.
- [Canvas](https://canvas.hubspot.com/) - HubSpot - the design system HubSpot uses to build its products.
- [Atlaskit](https://atlaskit.atlassian.com/) - Atlassian - official React UI library per the Atlassian Design Guidelines.
- [cf-ui](https://cloudflare.github.io/cf-ui/) - Cloudflare - packages to build UIs at Cloudflare with React.
- [Hack Club Design System](https://design.hackclub.com) - React components designed for speed, consistency, and best practices.
- [Mineral UI](https://mineral-ui.com/) - CA Technologies - open-source design system for modern software experiences.
- [MongoDB Design](http://mongodb.design/#/) - MongoDB - design for mission-critical applications.
- [Pivotal UI](https://styleguide.pivotal.io/) - Pivotal - React components styled for the Pivotal brand.
- [Plasma](http://plasma.guide/) - WeWork - design system for building internal business tools.
- [Pluralsight Design System](https://design-system.pluralsight.com/) - UI building blocks for cohesive design across Pluralsight products.
- [Priceline One](https://pricelinelabs.github.io/design-system/) - Priceline - design system focused on speed, consistency, and best practices.
- [Seek Style Guide](https://seek-oss.github.io/seek-style-guide/) - Seek - living style guide powered by React, webpack, CSS Modules and Less.
- [SpareBank 1 Design System](https://design.sparebank1.no/) - SpareBank - a common language for consistent design.
- [Spark Design System](https://sparkdesignsystem.com/) - Quicken Loans - patterns and components for Fintech products.
- [Swarm Design System](https://meetup.github.io/swarm-design-system/) - Meetup - UI components to quickly ship new products and features.
- [Uniform](http://uniform.hudl.com/) - Hudl - components, visual guidelines, language and resources.
- [Lightning Design System React](https://react.lightningdesignsystem.com/) - Salesforce - React implementation of the Lightning Design System.
