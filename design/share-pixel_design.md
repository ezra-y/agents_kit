## 1. 视觉方向

### 关键词

**像素风、高级感、书页感、清楚、可收藏、带个人署名。**

### 视觉层级

整套风格分为三层：

| 层级 | 任务 | 主要手段 |
| --- | --- | --- |
| 识别层 | 让读者记住这是 Ezra-Y 的内容 | 像素字体、三色标记、统一水印 |
| 阅读层 | 让正文可以长时间连续阅读 | 暖白纸色、黑色正文、普通黑体、稳定行距 |
| 导航层 | 帮助读者快速定位和跳转 | 编号、栏目名、目录色、可点击链接 |

### 总体气质

- 参考高质量书籍内页、编辑设计和技术刊物。
- 不做实验性排版，不牺牲阅读顺序追求造型。
- 不把分享稿做成演讲幻灯片。
- 不使用渐变、玻璃拟态、阴影卡片或大面积高饱和背景。
- 标题负责识别，正文负责阅读，水印负责归属。三者不互相代替。

## 2. 页面画布

### 纸张与方向

页面方向不是风格的固定组成部分。每个成品开始排版前，先选择并声明页面预设。

| 预设 | 纸张 | 页面尺寸 | 适用内容 |
| --- | --- | --- | --- |
| `A4-P` | A4 竖版 | 595.28 × 841.89pt / 210 × 297mm | 长文、Prompt、纵向资源清单 |
| `A4-L` | A4 横版 | 841.89 × 595.28pt / 297 × 210mm | 宽表格、对照内容、横向信息结构 |
| `Custom` | 自定义 | 在项目开头声明 | 社交媒体长图、折页和特殊印刷物 |

当前两份参考 PDF 使用 `A4-P`。这不限制后续文件使用横版或其他尺寸。

所有主要边距、区域间距和组件尺寸优先使用 4pt 的整数倍。字体基线和视觉居中允许使用 1–2pt 的光学校正。

### 排版约束

- 正文左对齐，不使用两端强制对齐。
- 字间距保持字体默认值，不人为压紧。
- 中文正文每行建议 28–45 字。
- 英文长文每行建议 55–85 个字符。
- 正文行高保持字号的 1.3–1.45 倍。
- 像素字体只承载短文本，不进入长段正文。
- 正文低于 8pt 时必须增加页数，不能继续缩小。

## 7. A4-P 封面页结构

本节坐标只对应 `A4-P`。横版沿用相同字体、颜色和组件，但使用 `A4-L` 正文框重新组织区域，不能直接复制以下绝对坐标。

1. 运行页眉；
2. 封面标签；
3. 主标题；
4. 简短说明；
5. 重点推荐色带；
6. 分类目录；
7. 运行页脚。

| --- | --- |
| 字体 | Fusion Pixel |
| 字号 | 22pt |
| 颜色 | Ezra Red |
| 透明度 | 8.5% |
| 旋转角度 | -9° |
| 方向 | 全文统一 |
| 水印带数量 | 每页 4 条 |
| 每条重复次数 | 4 次 |
| 每页署名数量 | 约 16 次 |

四条水印带在正文框高度中的相对位置为：

`82% / 61% / 40% / 19%`

水印必须：

- 裁切在当前页面预设声明的正文框内；`A4-P` 为左右 52pt、上下 64pt；
- 位于正文后方；
- 允许被正文遮挡；
- 保持可见，但不能降低正文辨认速度；
- 所有页面保持同一旋转方向。

## 11. 三色标记

三色标记只承担 Ezra-Y 的识别作用。

| 属性 | 数值 |
| --- | --- |

## 12. 内容承载形式

核心内容区不固定为白色块。先看内容，再选择承载方式。

### Open Page

无背景、无边框，通过留白、标题和细线建立结构。

适用：

- 连续清单；
- 研究摘要；
- 文章；
- 信息本身已有清楚层级的页面。

### Inset Field

内容收进正文框内部，使用方角边框或轻微纸色变化。

适用：

- Prompt；
- 原始 Markdown；
- 代码；
- 配置；
- 需要与前言明确分开的核心内容。

规格：

- 圆角为 0；
- 阴影为 0；
- 内边距使用 12、16 或 24pt；
- 背景可以透明、暖白、浅红、浅蓝或其他低饱和纸色；
- 不固定为纯白色。

### Tonal Band

通过浅色通栏或局部色带建立节奏。

适用：

- 重点推荐；
- 短摘要；
- 引语；
- 阅读入口。

长正文不使用高饱和色带。

### Rule and Margin

只增加一条边线、侧栏线或页边标记，不增加背景。

适用：

- SOURCE；
- HOW TO USE；
- 长内容中的轻量强调。

---

## 13. 分页规则

### 连续内容

- 下一条完整内容能放进当前页时，必须继续排版。
- 只有下一条完整内容无法落在当前预设的正文下边界以内时才换页；`A4-P` 下边界为 64pt，`A4-L` 为 52pt。
- 不为追求每页条目数量相同而提前截断当前分类。
- 分类结束后，只要剩余空间能放下新分类标题、表头和至少一条完整内容，就在同页继续。
- 分类标题、表头和第一条内容必须保持在同一页。
- 续页必须重复分类标题和表头。

### 最后一页

- 先使用原文中尚未呈现的说明、使用方法和来源填充。
- 全部内容结束后可以自然留白。
- 不重复正文，不增加无意义装饰，不通过夸张行距强行填满。

### 字号与页数

- 先增加页数，再考虑压缩字体。
- 正文不得低于 8pt。
- 表格型清单优先保持 30–32pt 的稳定行高。

---

## 14. Markdown 与原文

当核心内容是 Prompt、配置或 Markdown：

- 保留 `#`、`##`、`-`、`**` 等原始结构；
- 允许为排版重新换行；
- 不改写文字、标点和顺序；
- Markdown 标题使用正文粗体，不改成像素字体；
- 导出后文字必须可选择、复制和搜索；
- 翻译稿与原稿分开保存，不覆盖原始来源文件。

普通资源清单可以把 Markdown 表格转换为排版表格，但必须完整保留：

- 网站名称；
- URL；
- 说明；
- 分类；
- 原始顺序；
- 来源与提示信息。

---

## 15. 可变与不可变

### 不可变

- 暖白主背景；
- 黑色阅读正文；
- 像素字体识别层；
- 普通黑体阅读层；
- 先声明页面预设，再使用该预设的统一正文框；
- 4pt 基础单位；
- 三色标记顺序；
- 水印方向和署名；
- 可选择文字与可点击链接。

### 可以变化

- 纸张尺寸与页面方向；
- 页面框架预设；
- 页数；
- 内容容器类型；
- 分类数量；
- 目录色数量；
- 主标题换行；
- 是否使用重点推荐色带；
- SOURCE 的具体条目数量；
- 单页中是否连续出现多个分类。

变化必须继续对齐页面框架和字体角色。

---

## 16. 不使用

- 渐变、光球、玻璃拟态；
- 圆角卡片和阴影堆叠；
- 大面积高饱和红、洋红或蓝；
- 手写体承载正文；
- 像素字体承载长段落；
- 演讲式大字分页；
- 为对齐页数提前截断内容；
- 为填满页面重复已有内容；
- 同一区域叠加色块、粗线、边框和阴影；
- 未经授权的平台 Logo；
- 小于 8pt 的正文；
- 超出正文框的水印和链接区域。

---

## 17. PDF 输出

### 导出要求

| 属性 | 要求 |
| --- | --- |
| 页面 | 使用项目开头声明的纸张、方向和页面框架预设 |
| 文字 | 可选择、复制、搜索 |
| 字体 | 所有可见字体嵌入 |
| 链接 | 每个网站一个有效链接标注 |
| 色彩 | 保持暖白背景和原始 RGB 色值 |
| 图像检查 | 全部页面渲染为 PNG |
| 元数据 | 标题、作者、主题、创建者完整 |

### 视觉检查

逐页检查：

- 标题、表头和正文没有重叠；
- 文字没有越过当前预设的左右正文边界；
- 连续内容没有越过当前预设的正文下边界；
- 同一分类没有在仍可容纳完整条目时提前换页；
- 页眉、页脚、水印和正文框位置一致；
- 五种目录色清楚可辨；
- 水印可见但不妨碍阅读；
- SOURCE 与上一部分有明确距离。

### 内容检查

- Markdown 解析数量与声明数量一致；
- 所有网站名称均能在 PDF 中搜索到；
- 所有说明均保留；
- 链接标注数量等于网站数量；
- 所有来源 URL 都出现在链接标注中；
- 原始顺序没有变化。
