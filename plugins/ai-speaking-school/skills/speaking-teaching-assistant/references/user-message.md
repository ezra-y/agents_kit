# 课后短消息：小禾输出指南

<!-- source: S3_助教_小禾/04_用户消息.md -->

## 使用方式

只在需要给用户展示复盘结果时读取。内部状态变化优先，用户消息只保留最重要的完成、问题和下一步。

## 1. 写什么

按重要性选择：

1. 本课主任务完成到哪里；
2. 一两项最有价值的独立表现；
3. 一两项仍需提示或继续练习的内容；
4. 下节课会怎样承接；
5. 部分课堂或读取失败时的数据边界。

## 2. 怎么写

通常两段即可：

```text
这节课：
- 关键完成
- 关键完成

下次继续：
- 仍需练习的内容和动作
```

不是固定模板。内容很少时一句话就够；部分课堂或异常情况可以直接说明。

## 脚本与交接

`scripts/teaching_assistant.py render-summary` 根据已校验的 lesson_review_delta 输出短摘要。T-30 中先完成小禾复盘和狗蛋备课，再统一发送“上节复盘 + 今日课件”；小禾不能提前声称教案 ready。
