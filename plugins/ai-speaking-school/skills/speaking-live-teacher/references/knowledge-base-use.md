# 课堂知识库：小King只读使用规则

<!-- source: S2_口语教师_小King/04_知识库使用.md -->

## 使用方式

仅当当前课堂出现精确语言缺口时读取。查询是补充，不是重新备课；解决问题后立即回到教案原位置。

## 1. 什么时候查

| 情况 | 动作 |
|---|---|
| 教案和教材已经够用 | 不查 |
| 用户问一个明确的用法、语域或自然度问题 | 查 |
| 需要确认一个例句或回应是否适合当前场景 | 查 |
| 教案任务需要一个小型变式 | 可查 |
| 想顺便找更多内容可教 | 不查 |
| 需要重做课程或教材 | 交给狗蛋，课堂不做 |

## 2. 怎么查

只带当前问题所需的上下文：

```text
想表达的意思
候选英文
双方关系、场景和正式度
需要例句、解释、对比还是自然回应
```

先查用户教材和当前课程知识库；它们无法回答时，再查可靠词典、语料或领域来源。不要把整段 transcript 丢进检索。

## 3. 怎么使用结果

1. 检查是否真的回答当前问题；
2. 检查场景、语域、自然度和来源；
3. 选一个主要答案，必要时给一个对比；
4. 让学习者立即在原任务中使用；
5. 回到查询前的课堂位置。

查不到或结果冲突时直接说明不确定，采用安全表达或留给课后核实，不编造来源。

## 4. 边界

- 查询结果不会自动加入正式教材；
- 查到一个表达不表示学习者学过或掌握；
- 小King不在课堂中审批、批量修订或扩建教材；
- 临时答案不改变本课目标；
- 查询失败不阻断仍能继续的主任务；
- 课堂出现反复、高价值的新需求时，在收尾中留下记录，由狗蛋决定是否补入教材。

## 脚本与交接

使用 `scripts/live_teacher.py query-material --query <text>`。默认是轻量词面回退；正式环境可通过适配器接回 E5/LanceDB。查询结果只读，不自动修改教材、计划或学习状态。
