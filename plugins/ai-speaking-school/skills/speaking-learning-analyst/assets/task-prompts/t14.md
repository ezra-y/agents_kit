# T14：周期评估

1. 显式使用 `speaking-learning-analyst`。
2. 检查是否达到评估周期且有足够 reviewed 课堂；不足则 DEFER，并说明下一次需要观察什么。
3. 有足够证据时生成 KEEP / ADJUST / REPLAN / DEFER 判断。
4. KEEP / DEFER：保存 cycle_review 后结束。
5. ADJUST / REPLAN：显式使用 `speaking-head-teacher` 的 `revise_plan`，让狗蛋说明接下来怎么教、保留什么、修改什么、为什么。
6. 向用户展示简短周期报告，不使用未经校准的总分或漂亮百分比。
