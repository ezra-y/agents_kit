# 图文表达参考

这些是 2026 年 9 月研究时核对过的作品，用来参考表达方式，尚未成为 Ezra 的个人口味标准。需要参考哪种表达，就打开相应原图，结合画面阅读。

## 把依赖落实成一个动作

原图 `assets/ai-day.webp`，路径相对于咩咩工作目录。

别人问“你今天过得怎么样”，使用 AI 的人转身把这个问题交给 AI。第二格里另一人的表情也变了。它把宽泛的“依赖 AI”落在一个具体的社交动作上，人物关系与文字一起完成表达。

参考时可以从一个话题继续追问，人真的会因此做出什么动作。换到别的题目，场景与动作也应随之改变。

来源：小红书“小沈成长记”，《用上AI之后的我belike》，笔记 ID `6a69701d000000000f01452f`。采集时整帖 2,588 赞，包含多张图片。

## 让版面完成笑话

原图 `assets/free-will.webp`，路径相对于咩咩工作目录。

一个老电脑对话框问“你有自由意志吗”，两个按钮都回答“是的，我有”。可选择的外观和实际相同的选项形成了表达。窗口样式、文字和按钮共同参与；这张图可以直接研究版面怎样改变一句话的意思。

来源：小红书“S.I.A”，《做了点GPT的meme梗图》，笔记 ID `6825c6c80000000023002165`。采集时整帖 2,678 赞。原图保留英文，供研究，未作中文改图。

## 借熟悉的形式表达态度

原图 `assets/emoji-stats.jpg`，路径相对于咩咩工作目录。

视频把表情包当成游戏角色来评测。这个关键帧一边说表情没有攻击力，一边让红色区域冲出雷达图。读者对这个表情在聊天中的用法已有体感，专业评测的样式也成为玩笑的一部分。

它提示了一种可用选择：熟悉的表格、测试结果、游戏面板也可以进入创作。这里的评分图是作品的表现形式。

来源：B 站“爱鉴赏の子干”，《当表情包也有了战力图，你最爱哪个表情包呢？》，视频 ID `BV1fWbQ6UEFF`。采集时整条视频 249,766 赞；图片是约 70 秒的一个完整关键帧，数值不属于这一帧。
